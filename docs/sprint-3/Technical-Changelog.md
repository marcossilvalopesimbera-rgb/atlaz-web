# Technical Changelog

## Sprint 3.1

### UX/UI
- `InvestigationPageFrame` reorganizado como resumo executivo único com progressive disclosure para narrativa, cronologia, evidências e análise técnica.
- `context` e `workspace` atualizados para condução conversacional, confirmação de resposta e continuidade com foco e rolagem suave.
- `decidir` reduzido a status, recomendação e ação contextual; detalhes analíticos agora são opt-in.
- `evoluir` apresenta plano de validação prioritário com objetivo, impacto e justificativa; validações subsequentes ficam recolhidas.

### Limites arquiteturais
- Não houve alteração em Cognitive Runtime, engines, frameworks de confiança/evidência, governança ou aprendizagem.
